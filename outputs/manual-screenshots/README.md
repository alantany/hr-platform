# 产品说明手册截图目录

本目录存放 `outputs/产品说明手册.md` 第 6 章功能截图。

## 重新生成

本地服务需在 `http://127.0.0.1:8000` 运行，然后：

```bash
node scripts/capture-manual-screenshots.mjs
```

默认使用 `admin` / `admin123`，视口 1440×900，`fullPage` 截取。

## 命名

| 示例 | 含义 |
|------|------|
| `06-01-login.png` | 第 6.1 节主图 |
| `06-04-positions.png` | 同模块补拍（岗位 Tab） |
| `06-06-candidates-detail.png` | 详情弹窗补拍 |
