# 登录页视觉改版设计

日期：2026-07-18  
状态：待实现  
范围：仅登录页视觉与品牌区；不改认证逻辑

## 目标

将登录页从深蓝实色左栏样式，改为参考图中的浅色分栏风格，并新增六边形 **XL** logo。

## 视觉规格

### 布局

- 全屏背景：浅蓝（约 `#e0f2fe`）→ 白（`#ffffff`）渐变
- 右上角：淡色细弧线装饰（CSS/伪元素即可）
- 桌面：左右分栏（左品牌、右登录卡）
- 窄屏（约 ≤760px）：品牌区在上、登录卡在下

### 左侧品牌区

- Logo：内联 SVG
  - 蓝色正六边形（约 `#3b82f6`）
  - 白色粗体字母 **XL**（连笔风格尽量贴近参考图）
  - 外层半透明浅色六边形光晕
- 主标题：AI招聘管理平台
- 副标题：人力资源管理系统 v3.0
- 三个 pill 标签：智能招聘 / 权限管理 / 数据分析

### 右侧登录卡

- 白色圆角卡片 + 柔和阴影
- 标题：登录系统
- 字段：账号、密码（保留默认值 `admin` / `admin123`）
- 主按钮：蓝色「登录」
- 保留错误提示与踢下线文案（`reason=kicked`）
- 去掉偏长的说明脚注，更贴近参考图

## 实现方案

采用页内 SVG + 重写登录布局（方案 A）：

1. 改写 `src/pages/login.html` 的结构与页内样式
2. 调整 `styles.css` 中登录页相关 `!important` 覆盖，避免把新布局压回旧样式
3. 不改 `frontend-api.js` 登录请求、token 写入与跳转逻辑

## 非目标

- 不改侧栏/后台其他页面视觉
- 不新增独立 logo 资源文件（仅登录页使用内联 SVG）
- 不改 RBAC、鉴权接口或密码策略

## 验收标准

1. 桌面端视觉接近参考图：浅色背景、六边形 XL、右侧白卡
2. 窄屏布局可用，表单可提交
3. 正确账号可进入仪表盘；错误账号显示现有失败提示
4. 踢下线场景（`?reason=kicked`）提示仍可用

## 改动文件

- `src/pages/login.html`
- `styles.css`（仅登录页覆盖规则）
