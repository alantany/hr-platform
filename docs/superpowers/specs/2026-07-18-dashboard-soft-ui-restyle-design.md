# 首页数据看板 Soft UI 风格改版设计

日期：2026-07-18  
状态：待实现  
范围：仅首页看板视觉；不改功能与数据逻辑

## 目标

将当前扁平描边风格的数据看板（截图 2）改为截图 1 的 Soft UI：浅蓝底、白卡软阴影、更大圆角、日历实心选中态。空态保留，不加折线图。

## 决策

- 路径：**作用域样式升级**（`.dashboard-redesign`）
- 空态：**只改风格**，保留「选择指标或日期查看明细」，不做装饰折线图

## 视觉规格

### Tokens（看板作用域）

- 内容区背景：约 `#EEF5FF` → `#F7FAFF`
- 卡片：白底、圆角约 18px、软阴影；弱化灰描边
- 主色：约 `#3B82F6`
- 文字：标题深色、说明灰字
- 间距略加大

### 顶部 KPI

- 结构保持：标题、大数字、辅助文案、右上淡蓝圆底图标
- 默认：白卡 + 软阴影
- 选中：柔和蓝描边/浅阴影（去掉过重硬边）
- hover：轻微上浮

### 推荐日历

- 大白卡软阴影；月份切换按钮更轻
- 汇总 chip：浅蓝底 pill
- 选中日：实心蓝圆角块（白字）
- 有数据：蓝点 + 小数字；无数据弱化

### 月度数据看板

- 四宫格指标卡与顶部 KPI 同风格
- 底部空态：软 UI 居中（图标 + 主/次文案），不加折线图

## 实现范围

### 改动

- `styles.css`：`.dashboard-redesign` 及相关看板样式
- `src/pages/dashboard.html`：必要时微调 class / 缓存参数
- 侧栏/顶栏仅在与首页同屏时做轻微背景对齐（可选、尽量小）

### 不改

- `loadDashboardData`、指标计算、日历事件、筛选/明细逻辑
- API / RBAC / 其他业务页
- 不新增折线图组件或假数据图

## 验收标准

1. 桌面端视觉接近截图 1（软阴影浮卡、浅蓝底、日历实心选中）
2. KPI 点击筛选、日历选日、明细空态仍可用
3. 窄屏不崩版
