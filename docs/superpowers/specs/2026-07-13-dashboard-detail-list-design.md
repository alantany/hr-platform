# 首页日历/月度看板明细列表设计

**日期：** 2026-07-13  
**状态：** 已确认

## 目标

首页「推荐日历」与「月度数据看板」点击后，在月度看板下方同一区域展示对应明细；四种看板指标与日历选日交互一致，不再对「新增岗位」单独跳转。

## 交互

| 触发 | 展示内容 | 粒度 |
|------|----------|------|
| 日历某日 | 该日推荐候选人 | 候选人去重 |
| 本月面试数量 | 本月面试口径候选人 | 候选人去重 |
| 本月推荐数量 | 本月 `recommended_at` 候选人 | 候选人去重 |
| 本月入职数量 | 本月已入职候选人 | 候选人去重 |
| 本月新增岗位 | 本月新建岗位 | 岗位逐条（与数字一致） |

- 默认空态：「点击上方指标或左侧日历日期，在此查看明细」
- 触发源互斥；切换月份清空列表
- 提供「清空」按钮回空态
- 首版仅展示列表，不做行内复杂操作

## UI

统一行：主标题 + 右侧 chip；副信息一行；元信息一行。候选人与岗位共用同一套行样式，仅字段映射不同。

## 口径

复用现有 `getMonthlyMetrics` / `getCalendarEvents`，保证列表筛选条件与看板数字同源。候选人列表标题人数按去重后人数；岗位列表条数与看板数字一致。

## 实现范围

- `src/pages/dashboard.html`：状态、渲染、点击绑定、加载候选人
- `styles.css`：明细面板与行样式、月度卡选中态
- 更新 `findings.md` / `progress.md` / `task_plan.md`
